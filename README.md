# iop

임팩트 오브 파워(Impact of Power) 런처 · 밸런스 편집기

## 구성
- **v0.041:** 스타크래프트1 방식 리플레이. 컴퓨터 대전(싱글)과 멀티플레이 경기를 게임이 직접 자동 녹화하고, 경기가 끝나면 `Replays\LastReplay.ioprep`과 `Replays\Auto\날짜 맵 플레이어.ioprep`(최대 개수 지정, 오래된 것부터 정리)으로 저장합니다. 런처를 먼저 닫아도 녹화는 게임이 마무리하고 다음 실행 때 목록에 들어갑니다. [리플레이] 탭: 목록(날짜·맵·플레이어·방식·길이)·상세 정보·재생·마지막 경기 보기·이름 바꾸기·보관·삭제·가져오기/내보내기·`.ioprep` 더블클릭 연결. 재생은 메뉴 없이 바로 경기로 들어가며 게임 옆 조작창에서 일시정지·한 틱 진행·속도(×¼~×16)·처음부터·진행 막대·경과/전체 시간·전체 시야/플레이어별 시야 전환·전 플레이어 아다마스/플래티넘을 봅니다(키: P · +/- · N · V · H). 리플레이는 영상이 아니라 시작 설정과 실행된 명령 기록이며, 맵 파일을 함께 담고 재생 때 게임 데이터(밸런스)·실행 파일 차이를 미리 경고합니다. 재생 중 자원이 기록과 달라지면 조작창에 표시합니다. 녹화 코드는 관찰만 하므로 A·B 중 한쪽만 켜도 대전에 영향이 없습니다(끄기: [리플레이] 탭). 실제 게임 검증 범위는 [REPLAY_RESEARCH.md](REPLAY_RESEARCH.md).
- **v0.040:** 웹 맵 에디터 언덕을 클릭 한 번으로. [언덕 그리기]에서 모양과 크기(작게·보통·크게·아주 크게)를 고르고 지도를 클릭하면 절벽 테두리가 둘러진 언덕이 생기고 언덕 위는 고지대가 됩니다. 언덕 위를 다시 클릭하면 이어 붙고, 우클릭하면 그 언덕을 통째로 지웁니다. 게임 언덕 그림의 가로 2칸 덩어리(예: 10·11)를 맞춰 그려서 그림이 갈리지 않고, 기본 모양은 타일ID로 받은 실제 언덕(회색 돌·눈·사막 초록 기둥·사막·사막 바위·보라)에서 배웁니다. 게임 시야 규칙은 v0.038과 같습니다. [자세히](MAP_EDITOR.md)
- **v0.039:** 웹 맵 에디터를 라크무 에디터처럼 쉽게. [새 맵]은 기본 맵 대신 테마(보랏빛·스노우·흙색·사막 지형)만 고르면 그 테마 맵 전체의 타일로 빈 맵을 만듭니다. [언덕 그리기]는 모양을 고르고 드래그하면 마름모·타원·사각형 언덕이나 능선이 생기고 절벽이 자동으로 둘러집니다(미리보기, 우클릭 드래그로 지우기, 절벽 색 이름과 같은 지형 모양만 표시). [입구 놓기]는 언덕 가장자리에 마우스를 대면 입구가 미리 보이고 클릭하면 놓입니다(3칸 안이면 가장자리로 자동으로 붙음). 게임 시야 규칙은 v0.038과 같습니다. [자세히](MAP_EDITOR.md)
- **v0.038:** 고지대 시야 수정과 웹 맵 에디터 언덕 그리기. 실제 게임(treesnowopen1.1)에서 확인해 보니 패치는 정상 동작했지만, 4~6칸짜리 얇은 언덕은 양쪽 저지대가 보이고 게임의 시야 그림이 주변 3칸까지 섞어 그려서 언덕 위도 보이는 것처럼 나타났습니다. 이제 저지대의 지상 유닛·건물은 고지대 칸과 **고지대 너머**(관측자와의 직선이 고지대를 지나는 칸)도 보지 못합니다. 웹 에디터: [언덕 그리기]로 칠하면 설치된 맵에서 배운 대로 절벽이 자동으로 둘러지고(모양 고르기, 우클릭 지우기, 마름모 브러시), [자동 입구]는 언덕 가장자리를 클릭하면 맞는 입구를 놓습니다. [새 맵]은 지형(보랏빛·스노우·흙색·사막)을 고르면 아무것도 없는 빈 맵을 만듭니다. [선택-타일ID]로 영역을 고르면 타일 위에 번호가 표시되고 표로 복사할 수 있습니다. 왼쪽 버튼을 길게 누르면 화면 이동, 언덕·입구 견본은 크기 칸으로 크기를 바꿔 찍을 수 있습니다. **A·B 모두 v0.038 필요** (시야 규칙이 바뀌어 다른 버전과는 접속 시 차단). [자세히](MAP_EDITOR.md)
- **v0.037:** 웹 맵 에디터에 언덕·입구 만들기 추가. [언덕·입구] 도구로 견본을 고르고 클릭하면 그대로, 드래그하면 절벽 무늬를 반복해 원하는 크기로 찍습니다. 고지대 언덕은 언덕 위가 자동으로 고지대(시야 가림)가 되고, 낮은 언덕은 시야가 열린 채로 둡니다. [고지대 채우기]는 언덕 위를 한 번 클릭하면 절벽과 입구로 둘러싸인 곳 전체를 고지대로 지정합니다. 다른 맵의 언덕·입구를 선택해 [견본으로 저장]하면 같은 테마의 모든 맵에서 쓸 수 있습니다. [자세히](MAP_EDITOR.md)
- **v0.036:** 웹 맵 에디터가 게임 데이터(`data/Rsi.res`)의 실제 자원·나무/장식 그림을 맵 위에 그립니다. 자원 도구는 놓일 자리에 자원 그림을 미리 보여 줍니다. 타일 팔레트를 도구 바로 아래로 옮기고 크게 했으며, 맵을 열면 맵 목록이 접히고 타일 그림이 보이는 배율(16)로 P1 근처에서 시작합니다. [간단 표시]를 켜면 예전 ◆·■ 표시로 돌아갑니다.
- **v0.035:** 웹 맵 에디터 추가. [멀티 맵 에디터] 탭의 [웹 맵 에디터 열기]를 누르면 런처가 127.0.0.1에 로컬 서버를 띄우고 브라우저로 엽니다. 브러시 크기·원형, 스포이드, 지우기, 고지대 칠하기/해제, 자원, 시작 위치, 영역 선택(복사·붙여넣기·채우기·평지·자원/장식 삭제), 다시 실행, 미니맵, 표시 레이어, 새 맵(크기·인원 지정), 맵 속성(인원 변경), 시작 위치 검사를 지원합니다. map/multi에 바로 저장하고 기존 파일은 .bak으로 보관합니다. 자원 매장량은 IOP 맵에 저장되지 않아 편집할 수 없습니다. [자세히](MAP_EDITOR.md)
- **v0.034:** 고지대 시야 재설계. v0.032는 고지대를 게임 타일 칸 값의 비트 0x100에 저장했는데, 게임은 같은 값에 자원·건물의 점유 비트(0x0010~0x8000)를 OR로 찍습니다. 그래서 자원 칸이 고지대로 오인되어 저지대 지상 유닛에게 자원이 보이지 않았습니다. 이제 고지대는 패치 전용 비트맵(게임 malloc 0x26000바이트)에만 저장하고 게임 칸 값에는 넣지 않습니다. 에뮬레이션에서 자원이 있는 맵의 런타임 칸 값이 원본 게임과 완전히 같고 자원이 계속 보이는 것을 확인. 실제 게임·두 PC 대전은 미확인. A·B 모두 v0.034 필요. [자세히](MAP_EDITOR.md)

- `iop_network.py`, `iop_server_tab.py`, `iop_admin.py`, `iop_elevation.py`, `iop_sync.py`, `iop_server/` — 내장 서버와 런처 통합 기능

빌드된 exe는 게임 폴더(iop.exe 가 있는 곳)에 두고 실행합니다.

리플레이 기계어를 고치면 `python tools/build_replay_patch.py`(nasm 필요)로 `iop_replay_code.py`를 다시 만듭니다. Windows 빌드 환경이 없을 때는 `python3.12 tools/repack_release.py release/v이전/IOPLauncher_Server.exe 새.exe`로 이전 배포본의 부트로더·런타임을 그대로 두고 프로젝트 모듈만 교체할 수 있습니다.
